# 潜力雷达 · 选品系统

当前已发布首版的源码备份。提供商品机会评分、利润测算、筛选对比、候选池、验证记录和 JSON 导入导出。

## 本地运行

无需安装依赖，可直接打开 `dist/index.html`。也可运行：

```sh
python3 -m http.server 8080 --directory dist
```

然后访问 http://localhost:8080。

## 文件

- `dist/index.html`：选品工作台
- `dist/style.css`：响应式样式
- `dist/core.js`：评分、利润及输入校验
- `dist/app.js`：交互、导入导出与浏览器本地存储

## 当前能力边界

- 内置商品是演示数据，尚未连接电商平台实时数据。
- 评分是可调整权重的启发式规则，未经历史回测，不代表爆款概率。
- 利润扣除采购、物流、广告、平台费及退货预留，未完整覆盖税费、仓储、人工和汇率风险。
- 用户数据仅保存在当前浏览器，请定期导出备份；仓库不包含用户浏览器中的私有选品记录。
- JavaScript 语法、利润计算、评分与部分输入边界校验已通过，浏览器端交互验证尚未完成。

本仓库保留原始 Git 历史，仅同步应用源码；不包含 Sites 部署身份或访问凭证。
